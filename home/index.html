Type a name, get a site.

Doorway is a small app for your computer. Type a name like commonplace and it opens the site, from whichever doors have it, checked byte by byte against the address its name points to. Every name gets its own address on your computer, commonplace.localhost, in your normal browser.

It keeps one key for you, for every site, and asks before anything is written with it. The first time, it takes a little CSD someone left for newcomers, so writing just works.

A site lasts as long as anyone thinks it should.

On the web, a page dies the day one person stops paying for it. Here, anyone can keep any site up, a year at a time, for 0.25 CSD a year: the doors keep it until its time runs out, whether or not a name still points to it. Years stack, anyone can add more, and anyone can check how long a site is kept from the network itself.

A whole app is one page.

No server, no database, no accounts. The kit reads a topic from any door and checks every record in the browser; writing is signed by a key the page keeps, or by Doorway's. Publish the folder with Doorway and point a name at it.

import { connect, writingKey } from "compute-substrate";

const net = connect();
const me = await writingKey("guestbook");
await net.write(me.signer(net), "guestbook.example", "Hello");
const entries = await net.read("guestbook.example");   // each one checked

One command, on any small server.

A door serves the network to browsers and keeps the sites names point to and people keep up. It needs no domain and no approval: it announces itself on the network, and Doorway finds it.

curl -fsSL https://github.com/compute-substrate/compute-substrate/releases/download/app-v0.2.3/door.sh | bash
How a door works
Nothing to trust

Every page and record is checked on your own computer, against its address and the network's proof-of-work. A door can refuse to answer; it can't change a byte.

No accounts

You are a key. Nobody can lock you out, and nobody needs your email.

No owner

Anyone can run a node or a door, and none of them is special. The rules are the code everyone runs.

Writing costs a stamp

Each record costs a little CSD, the network's unit. Spam doesn't pay, so nobody has to moderate it away.
